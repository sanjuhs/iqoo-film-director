# Mini Film — phone director research prototype

Fresh implementation dated 4 October 2026. This is pre-event research, not event-written competition source. The public guide restricts finale code to October 9–11 unless organizers approve reuse.

## What runs

Native Android app with three screens: **Brief → Direct → Assemble**. Fashion is the first workflow; talking head, introduction and product reveal starters are included. Editable five-shot plans can be generated by a local CPU LLM. Bundled pose inference supplies conservative framing cues. Offline English speech synthesis follows Android's selected audio output. CameraX supplies explicit foreground phone capture. The editor retains originals, supports selection/order/trim, timed editable English speech subtitles, typography and color presets, and exports a vertical MP4 plus JSON cut list locally.

Local reference inspection samples colors, rough scene changes and person landmarks. It is not semantic trend understanding. The optional full-shot sequence speaks instructions between takes, waits eight seconds plus a three-second countdown, and auto-stops each take. Stop or leaving the app ends the sequence; it never resumes on return. This sequence and real camera capture still need an attended shoot check.

## Build and install

Reuse the installed Android SDK, NDK 28.2.13676358, CMake 3.22.1, JDK 17 and cached Gradle 8.14. No provider credential is required. `tools/build.sh` uses the existing Homebrew JDK if JAVA_HOME is unset.

Fetch the two ignored official source dependencies at the revisions checked by CMake:

```sh
git clone --filter=blob:none https://github.com/ggml-org/llama.cpp.git app/src/main/cpp/llama.cpp
git -C app/src/main/cpp/llama.cpp checkout 11fe02151f79c41d0d4af7da708755d73b9c0da6
git clone --filter=blob:none https://github.com/ggml-org/whisper.cpp.git app/src/main/cpp/whisper/vendor/whisper.cpp
git -C app/src/main/cpp/whisper/vendor/whisper.cpp checkout a8d002cfd879315632a579e73f0148d06959de36
./tools/build.sh :app:assembleDebug :app:assembleDebugAndroidTest
adb -d install -r app/build/outputs/apk/debug/app-debug.apk
adb -d shell am start -n dev.minifilm.director/.MainActivity
```

The app has no Internet permission. Camera/microphone prompts appear only after the corresponding action. Models are separate ignored local files, not packaged in the APK. Current development-device files are `files/director-model.gguf` (Qwen3.5 0.8B Q4_0) and `files/models/ggml-tiny.en.bin`. Their hashes/provenance and pinned runtimes are recorded in [local AI evidence](../../docs/local-ai-evidence.md) and [transcription evidence](../../docs/transcription-evidence.md). Missing models retain the editable starter plan/manual captions. Optimized LLM instructions are verified for Phone (3a); check hardware before testing another phone, or build the portable baseline described in the evidence document.

## Reproduce checks

Install the test APK; prepare only the labelled synthetic/public fixtures specified in the evidence documents. No test needs a camera or microphone permission grant, private footage, cloud request or aircraft.

```sh
adb -d install -r app/build/outputs/apk/androidTest/debug/app-debug-androidTest.apk
adb -d shell am instrument -w -e class dev.minifilm.director.LocalAITest dev.minifilm.director.test/androidx.test.runner.AndroidJUnitRunner
adb -d shell am instrument -w -e class dev.minifilm.director.MediaWorkflowTest dev.minifilm.director.test/androidx.test.runner.AndroidJUnitRunner
adb -d shell am instrument -w -e class dev.minifilm.director.ReferenceAnalyzerTest dev.minifilm.director.test/androidx.test.runner.AndroidJUnitRunner
adb -d shell am instrument -w -e class dev.minifilm.director.UiWorkflowTest dev.minifilm.director.test/androidx.test.runner.AndroidJUnitRunner
```

Measured CPU plans: 52.553 seconds fashion and 46.473 seconds product on the connected Phone (3a). Four media checks passed, including real decoded subtitle visibility after trims, synthetic speech transcription, vertical clip assembly and safe cancellation. Reference and pose checks establish execution on fixtures, not accuracy on unseen creators. [Current status](../../docs/status.md) contains the complete measured ledger and failures.

## Demo and outstanding checks

[Demo runbook](../../docs/demo-runbook.md) and [Phase 1 pitch](../../docs/submission-draft.md) separate verified features from planned hardware. Use **Try synthetic demo clips** to inspect assembly without capturing anyone. The in-app player opens local clips paused and releases playback when leaving. For an attended real shoot, pair earbuds in Android settings, verify audible direction, review a plan, allow normal camera/audio prompts, and keep the phone app visible. Cues stay quiet during recording; recorded audio uses CameraX's Android input route, not a guaranteed AirPods microphone.

AirPods, real creator capture, full sequence, iQOO execution/NPU and Office Kit integration remain separate checks. DJI, Action 4 and Neo 2 control are not connected. No flight action or drone recording is implemented. Creative drafts may invent details and always require editing.

The app can save its editable cut list through Android's user-chosen document
picker for local Files/Office Kit transfer preparation. The JSON references its
original phone source URIs; it is not a self-contained desktop editor project.
[Office Kit acceptance research](../../docs/office-kit-research.md) and
[packaged third-party notices](../../docs/third-party-notices.md) document the remaining gates.
