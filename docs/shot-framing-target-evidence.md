## Explicit editable intent

Edit shot now offers Scene default (suggested), Full outfit, Face & shoulders,
Object / detail and Manual preview only. Save applies the choice; Cancel keeps
the shot. The setting appears on the plan and Direct screen. It is creator intent,
not a learned model decision. Existing/missing/invalid restored values retain
scene_default. Fresh generated/template plans still use this default; targets
are not automatically inferred from a spoken brief or learned from footage.

Explicit Full outfit and Face & shoulders enable person advice even under an
object-like title/Product scene. Face & shoulders omits the shoe check. Object /
detail and Manual preview only exclude person analysis. Scene default preserves
the earlier style/title policy, including Fashion's qualified shoe suggestion.
No landmark score certifies pose readiness or controls recording. Existing
geometric thresholds, explicit capture, quiet countdown/recording and pose-break
completion rules remain.

PoseCoach snapshots immutable target/style configuration before submitting a
frame and checks its exact identity again before emitting. Changing A→B→A cannot
revive the old snapshot. This bounds callback admission for target changes;
it does not prove frame age, live usefulness or native-task abort timing.

## Saved samples and portable metadata

Saved-cut review resolves exact current capture/creator-reviewed IDs. Exactly
one current match can supply an explicit target. No match, multiple distinct
matches or scene_default abstain to manual review. This is the current plan's
intent, not a frozen assertion of what framing was intended at capture time.
The association/target binding is snapshotted and rechecked before a result is
shown. Target-qualified hints retain ordinary landmark labels and uncertainty;
object landmarks do not assess objects, and unconfirmed lower body does not
prove cropped feet. Three sampled approximate9:16 frames remain separate from
motion, quality and semantic coverage evaluation.

Immutable plan snapshots validate and freeze canonical target keys. Export
edit JSON/portable JSON add optional framingTarget to existing v1 shot entries;
identity, cuts and timing semantics remain. Readable shoot notes distinguish
creator choices from a scene-default suggestion. Plan renewal preserves target
while creating independent shots/new IDs. Changing framing choice contributes
to the existing package fingerprint and invalidates an outdated prepared pack.
